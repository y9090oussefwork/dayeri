## 📖 نبذة عن اللعبة | About The Game

**«ع الدائري» (Dayery / Cairo Ring Road)** هي لعبة قيادة وسواقة ثلاثية الأبعاد (3D WebGL) مجانية ومفتوحة المصدر، تجسد تجربة السواقة الحقيقية على الطريق الدائري في محافظة القاهرة الكبرى بكامل تفاصيله وروح الشارع المصري.

تم تصميم وبناء اللعبة بتقنيات الويب الحديثة (**Three.js & WebGL**) لتعمل مباشرة من المتصفح على أي جهاز (كمبيوتر، لابتوب، هواتف أندرويد وآيفون) بأعلى أداء (60 FPS) وبدون الحاجة لأي تحميل أو تثبيت برامج أو تسجيل حساب.

> **"ع الدائري" ليست مجرد لعبة سيارات عادية، بل محاكاة حقيقية للزحمة المصرية: ميكروباصات تقف فجأة للركاب، توكتوك يكسر عكس الاتجاه، تريلات عملاقة في الحارة الشمال، رادارات ونزلات المحاور الشهيرة، مع أصوات الكلاكسات والأغاني الشعبية.**

## ✨ المميزات الرئيسية | Key Features

### 🛣️ خريطة واقعية للطريق الدائري (Real Cairo Ring Road GIS)
- مسار الطريق الدائري الحقيقي بطول يزيد عن 100 كيلومتر مع اليافطات الخضراء والزرقاء ونزلات ومطالع القاهرة والجيزة والقليوبية (المنيب، التجمع، الأوتوستراد، المرج، شبرا، المعادي، الهرم).

### 🚐 أسطول المركبات المصرية الأصيلة
- **الميكروباص الأبيض:** ملوك الدائري والزجزاج بين الحارات.
- **التوكتوك:** للمناورة السريعة والهروب من الزحمة.
- **التريلا العملاقة:** شاحنة نقل ثقيل بحمولات وضخامة مرعبة.
- **التاكسي وملاكي شاهين وبيجو:** سيارات الشارع المصري الكلاسيكية.
- **الموتوسيكل:** سرعة فائقة واختراق بين العربيات.

### 🎨 محرك الجرافيك الفائق 4K (Ultra Graphics AAA Engine)
- **إضاءة سينمائية (ACES Filmic Tone Mapping):** درجات ألوان واقعية لسماء وتربة وشمس القاهرة.
- **ظلال ناعمة تفاعلية (PCF Soft Shadows 2048x2048):** تتبع مسار حركة السيارة طوال الطريق.
- **تصفية إكساءات خارقة (16x Anisotropic Filtering):** وضوح ونقاء فائق لخطوط الأسفلت واللافتات المرورية.
- **عجلات ثلاثية الأبعاد تفاعلية (Spinning & Steering 3D Wheels):** دوران فيزيائي للعجلات يطابق سرعة الأسفلت مع انحراف واقعي عند التوجيه وظل التحام يثبت السيارة بالأرض.
- **كشافات ليلية حقيقية (Headlights Projection):** إسقاط ضوئي واقعي للكشافات على الطريق في الأجواء المظلمة.

### 🏛️ معالم مصر الحضارية والسياحية ثلاثية الأبعاد
- إطلالات ثلاثية الأبعاد على معالم القاهرة التاريخية والحديثة أثناء السواقة (الأهرامات، برج القاهرة، المتحف المصري الكبير GEM، القلعة، والبرج الأيقوني بالعاصمة الإدارية).

### 🎥 كاميرا الكابينة والمنظور الداخلي (Cockpit First-Person View)
- إمكانية التبديل الفوري بين منظور الكاميرا الخارجية ومنظور السائق من داخل كابينة السيارة عبر زر الشاشة أو مفتاح `C`.

### 🔧 ورشة التعديل والترقيات (Garage & Customization)
- ترقية الموتور، الفرامل، الثبات، وتغيير الألوان والنمر المصرية وتثبيت الكماليات.

## 🎮 التحكم وأزرار اللعب | Controls

| الوظيفة / Action | الكمبيوتر / Desktop | الموبايل / Mobile |
| :--- | :--- | :--- |
| **التوجيه يميناً ويساراً (Steer)** | الأسهم `←` `→` أو `A` / `D` | أزرار اللمس على الشاشة |
| **الفرامل والتراجع (Brake)** | السهم لأسفل `↓` أو `S` | دواسة الفرامل باللمس |
| **آلة التنبيه / الكلاكس (Horn)** | مفتاح المسطرة `Space` أو `H` | زر الكلاكس |
| **تبديل كاميرا الكابينة (Cockpit)** | مفتاح `C` | زر تبديل الكاميرا بالزاوية العلوية |
| **إيقاف مؤقت (Pause)** | زر `Esc` أو `P` | زر الإيقاف بالواجهة |

## 🚀 طريقة التشغيل محلياً | How to Run Locally

المشروع مبني بالكامل على تقنيات الويب النقية (Pure Vanilla HTML5/CSS3/JavaScript & WebGL)، **لا يتطلب أي بناء (No Build Step) أو تثبيت حزم معقدة**:

### الطريقة الأولى: باستخدام بايثون (Python)
```bash
# 1. استنسخ المشروع
git clone https://github.com/y9090oussefwork/dayeri.git

# 2. ادخل لمجلد المشروع
cd dayeri

# 3. شغّل سيرفر محلي فوري
python -m http.server 8080
```
افتح المتصفح على: `http://localhost:8080/`

### الطريقة الثانية: باستخدام Node.js
```bash
npx serve .
# أو
npx http-server -p 8080
```

### الطريقة الثالثة: عبر VS Code Live Server
فقط افتح المجلد في **Visual Studio Code** واضغط كليك يمين على ملف `index.html` واختر **Open with Live Server**.
